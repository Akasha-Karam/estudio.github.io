1. Introducción a Java

1.1 ¿Qué es Java?

Java es un lenguaje de programación de propósito general, orientado a objetos y multiplataforma. Fue creado por Sun Microsystems (hoy Oracle) y se ejecuta sobre la JVM (Java Virtual Machine), lo que permite que el mismo código funcione en Windows, Mac o Linux sin cambios. Su lema es "write once, run anywhere".

ComponenteQué es
JDKJava Development Kit. Lo que necesitas para programar en Java.
JREJava Runtime Environment. Lo que necesitas para ejecutar programas Java.
JVMJava Virtual Machine. La máquina virtual donde corre el código.
¿Por qué Java?

Es uno de los lenguajes más usados del mundo: aplicaciones Android, sistemas bancarios, APIs empresariales (Spring Boot), big data (Hadoop)… y es la base para entender lenguajes derivados como Kotlin o Scala.

1.2 Tu primer programa

El "Hola Mundo" en Java se ve así:

HolaMundo.java
public class HolaMundo {
    public static void main(String[] args) {
        System.out.println("¡Hola, mundo!");
    }
}
  • class HolaMundo: todo en Java vive dentro de una clase.
  • public static void main(String[] args): el punto de entrada. Java empieza a ejecutar siempre desde este método.
  • System.out.println(…): imprime una línea por consola.
Compilar y ejecutar
javac HolaMundo.java    # compila → genera HolaMundo.class
java HolaMundo          # ejecuta

En IDEs como IntelliJ IDEA, Eclipse o VS Code esto se hace pulsando el botón ▶ "Run".

2.3 Expressions

Una expressió és una combinació de variables, constants i operadors que, en ser avaluada, produeix un únic valor.

Els operadors són els símbols que indiquen quina operació es fa entre els valors. Segons la seva funció es classifiquen en aquestes categories:

CategoriaOperadorsSecció
Aritmètics + - * / % 2.3.1
Relacionals == != < > <= >= 2.3.2
Lògics && (AND) · || (OR) · ! (NOT) · ^ (XOR) 2.3.3
Assignació = += -= *= /= %= 2.3.4
Increment / decrement ++ -- 2.3.5
Idea clau

Una expressió es calcula i sempre produeix un únic resultat. L'operador indica quina operació s'aplica i el tipus del resultat depèn dels operands.

2.3.1 Expressions numèriques

Són expressions que operen amb dades de tipus int o double. Serveixen per realitzar càlculs matemàtics i transformacions de dades.

Operador Significat Exemple
+ Suma 5 + 2 → 7
- Resta 5 - 2 → 3
* Multiplicació 5 * 2 → 10
/ Divisió 10 / 2 → 5
% Residu o mòdul 10 % 3 → 1

Divisió entre int: truncar

Quan es divideixen dos valors de tipus int, Java retorna un resultat de tipus int. La part decimal desapareix.

Truncar no és arrodonir

Truncar significa eliminar completament la part decimal sense aplicar cap regla d'arrodoniment.

Expressió Resultat matemàtic Resultat a Java
10 / 3 3.333... 3
19 / 5 3.8 3
5 / 2 2.5 2
8 / 4 2 2

Per exemple: 

int resultat = 10 / 3;
// resultat = 3
Important amb double

Si primer es fa la divisió entre dos int, els decimals ja s'han perdut abans de guardar el resultat en un double. 

double resultat = 10 / 3;
// resultat = 3.0

Com obtenir decimals: càsting

Per obtenir un resultat decimal, com a mínim un dels operands ha de ser de tipus double abans de fer la divisió.

Opció 1: utilitzar un literal decimal

double resultat = 10.0 / 3;
// resultat = 3.333333...

Opció 2: utilitzar càsting

int totalPunts = 10;
int jugadors = 3;

double mitjana = (double) totalPunts / jugadors;
// resultat = 3.333333...
Divisió Resultat
int / int int
double / int double
int / double double
double / double double
Divisió per zero

No es pot dividir un valor enter entre 0. En Java, una divisió entera entre zero provoca una ArithmeticException. 

int resultat = 10 / 0;
// ArithmeticException

Mòdul %: el residu

L'operador % no calcula el quocient de la divisió. Retorna el residu, és a dir, el que sobra després de fer una divisió entera. 

10 % 3

10 / 3 = 3
3 * 3 = 9
10 - 9 = 1

// 10 % 3 = 1
Expressió Residu
10 % 3 1
10 % 2 0
15 % 4 3
20 % 5 0

Utilitzar % per saber si un número és parell

Si el residu d'un número dividit entre 2 és 0, el número és parell. 

numero % 2 == 0

Si el residu és diferent de 0, el número és senar. 

numero % 2 != 0
Regla ràpida

% 2 == 0 → parell
% 2 != 0 → senar

Reiniciar un índex amb %

El mòdul també es pot utilitzar per fer que un índex torni a començar des de 0.

Per exemple, la paraula "kuruma" té 6 caràcters: 

k  u  r  u  m  a
0  1  2  3  4  5

Si volem continuar recorrent la paraula després de l'índex 5, podem utilitzar: 

i % texto.length()

1 1 % 6 = 1 1 u
2 2 % 6 = 2 2 r
3 3 % 6 = 3 3 u
4 4 % 6 = 4 4 m
5 5 % 6 = 5 5 a
6 6 % 6 = 0 0 k
7 7 % 6 = 1 1 u

D'aquesta manera podem utilitzar: 

text.charAt(i % text.length())

i l'índex torna a començar automàticament des de 0 quan arriba al final del text.

2.3.2 Operadors de relació o comparació

Una expressió booleana és una expressió que només pot produir un dels dos valors: true o false. S'utilitzen per prendre decisions amb estructures com if i per controlar bucles.

Els operadors de comparació serveixen per comparar dos valors i obtenir un resultat booleà.

Regles importants
  • Cada operador de comparació compara dos valors alhora.
  • En les comparacions numèriques (==, !=, <, >, <=, >=) es poden comparar valors de tipus diferents, com int i double.
  • No es poden comparar tres valors alhora amb una sola expressió de comparació. Per comparar més valors o establir diverses condicions, s'utilitzen els operadors lògics (&&, ||, etc.).
  • Els valors han de ser compatibles amb l'operador utilitzat.
Operador Significat Exemple
== Igual a edat == 18
!= Diferent de edat != 18
> Major que preu > 50
< Menor que puntuacio < 0
>= Major o igual stock >= 1
<= Menor o igual temperatura <= 36.5

Exemples amb valors concrets

int edat = 20;
double preu = 50.0;
double temperatura = 36.5;

System.out.println(edat == 18);           // false
System.out.println(edat != 18);           // true
System.out.println(preu > 50);            // false
System.out.println(preu >= 50);           // true
System.out.println(temperatura <= 36.5);  // true

També es poden comparar valors numèrics de tipus diferents, com int i double: 

int a = 5;
double b = 10.5;

System.out.println(a < b);   // true
System.out.println(a == b);  // false
Atenció: = no és ==

= assigna un valor a una variable; == compara dos valors i retorna true o false. Escriure if (edat = 18) és un error.

Comparar textos

Per comparar dos String no s'ha d'utilitzar ==. Cal utilitzar text1.equals(text2).

Això passa perquè String és un tipus per referència: == compara la direcció de memòria on està guardat l'objecte, no el seu contingut. En canvi, equals() compara caràcter a caràcter el text de les dues cadenes.

Per saber-ho amb més detall, consulta 6. Strings (cadenes de text).

Comparar més de dos valors

No es pot escriure una comparació com aquesta en Java: 

// Incorrecte
a < b < 20
Per què no funciona?

Java avalua primer a < b, que ja retorna un boolean. Després intenta comparar aquest boolean amb 20, i això no és permès.

Si volem comprovar diverses condicions, hem d'utilitzar operadors lògics: 

int edat = 20;

System.out.println(edat >= 18 && edat <= 65); // true

En aquest cas, es fan dues comparacions:

  • edat >= 18 → true
  • edat <= 65 → true

Com que les dues condicions són certes, el resultat final és true.

El resultat d'una comparació es pot utilitzar directament en un if: 

int nota = 7;

if (nota >= 5) {
    System.out.println("Aprovat");
} else {
    System.out.println("Suspès");
}
Idea clau

Els operadors de comparació comparen dos valors cada vegada. Si necessitem comprovar diverses condicions, podem combinar les comparacions amb operadors lògics com && (AND) i || (OR).

2.3.4 Operadors d'assignació

Serveixen per guardar un valor dins d'una variable. L'operador bàsic és =; les formes compostes fan una operació i assignen el resultat a la mateixa variable.

edat /= 3;       // edat = 30 / 3 = 10

2.3.5 Operadors d'increment i decrement

++ suma 1 a una variable i -- li resta 1. Són molt habituals en els bucles. 

int i = 5;

i++;            // i passa a 6
i--;            // i torna a 5

for (int j = 0; j < 3; j++) {
    System.out.println(j);  // 0, 1, 2
}

Es poden escriure abans o després de la variable. La diferència es nota quan s'utilitza el valor dins d'una altra expressió:

System.out.println(a);    // 6

int b = 5;
System.out.println(++b);  // b passa a 6 i mostra 6

3. Estructuras de control

Son las que deciden qué se ejecuta y cuántas veces.

3.1 Estructuras condicionales: if / else

¿Qué es un if?

El if sirve para ejecutar un bloque de código solo si una condición es verdadera (true).

La condición debe dar un resultado booleano: true o false. 

int edat = 20;

if (edat >= 18) {
    System.out.println("Ets major d'edat");
}
  • Si la condición es true, se ejecuta el código del if.
  • Si la condición es false, se salta el bloque y el programa continúa con las instrucciones siguientes.

if solo

Se utiliza cuando queremos ejecutar una acción únicamente si se cumple una condición. 

int num = 10;

if (num > 0) {
    System.out.println("El nombre és positiu");
}

Si num es mayor que 0, muestra el mensaje. Si no lo es, no hace nada dentro del if.

Importante: el if no necesita obligatoriamente un else. Podemos utilizarlo solo.

if / else

Se utiliza cuando queremos ejecutar una acción si se cumple una condición y otra acción diferente si no se cumple. 

int edat = 16;

if (edat >= 18) {
    System.out.println("Ets major d'edat");
} else {
    System.out.println("Ets menor d'edat");
}
  • if: se ejecuta si la condición es verdadera.
  • else: se ejecuta si la condición es falsa.

El programa ejecuta uno de los dos bloques, nunca ambos.

Importante: el else es opcional. Solo lo ponemos cuando queremos indicar qué debe hacer el programa si no se cumple la condición.

if / else if

Se utiliza cuando queremos comprobar varias condiciones diferentes. 

int nota = 7;

if (nota >= 9) {
    System.out.println("Excel·lent");
} else if (nota >= 5) {
    System.out.println("Aprovat");
}
  • Si la nota es igual o superior a 9, muestra Excel·lent.
  • Si la primera condición es falsa, comprueba si la nota es igual o superior a 5.
  • Si ninguna condición se cumple, no se ejecuta ninguno de los bloques.

Podemos añadir tantos else if como necesitemos.

if / else if / else

Se utiliza cuando tenemos varias condiciones y queremos establecer una acción final si ninguna se cumple. 

int nota = 3;

if (nota >= 9) {
    System.out.println("Excel·lent");
} else if (nota >= 5) {
    System.out.println("Aprovat");
} else {
    System.out.println("Suspès");
}

En este caso, muestra Suspès porque la nota no cumple ninguna de las dos primeras condiciones.

El else final recoge todos los casos en los que no se cumple ninguna condición anterior.

Recuerda

En una misma estructura if / else if / else, cuando se cumple una condición, se ejecuta su bloque y se saltan las demás alternativas.

Varios if independientes

Podemos poner varios if seguidos cuando queremos comprobar diferentes condiciones que pueden cumplirse al mismo tiempo. 

double compra = 120;
boolean esSocio = true;

if (compra >= 50) {
    System.out.println("Enviament gratuït");
}

if (compra >= 100) {
    System.out.println("Descompte de 10 euros");
}

if (esSocio) {
    System.out.println("Descompte per ser soci");
}

Resultado:

Enviament gratuït
Descompte de 10 euros
Descompte per ser soci

Se muestran los tres mensajes porque las tres condiciones son verdaderas.

¿Por qué utilizamos varios if?

Porque queremos comprobar cada condición de manera independiente. Aunque se cumpla el primer if, el programa continúa comprobando los siguientes.

Si utilizáramos else if, solo se ejecutaría el primer bloque cuya condición fuera verdadera, y los demás se saltarían.

Diferencia entre if independientes y else if

Estructura Funcionamiento
Varios if independientes Comprueba todas las condiciones y puede ejecutar varios bloques.
if / else if Comprueba las condiciones en orden y ejecuta como máximo uno de los bloques.
if / else if / else Igual que el anterior, pero incluye una alternativa final si ninguna condición se cumple.

Ejemplo para recordar la diferencia:

int num = 10;

if (num > 0) {
    System.out.println("Positiu");
}

if (num >= 10) {
    System.out.println("Gran o igual a 10");
}

Los dos mensajes se muestran porque son dos if independientes.

En cambio:

int num = 10;

if (num > 0) {
    System.out.println("Positiu");
} else if (num >= 10) {
    System.out.println("Gran o igual a 10");
}

Solo se muestra Positiu, porque la primera condición ya se cumple y se salta el else if.

Todas las combinaciones

1. Solo if

if (condicio) {
    // Codi
}

2. if / else

if (condicio) {
    // Si és true
} else {
    // Si és false
}

3. if / else if

if (condicio1) {
    // Codi 1
} else if (condicio2) {
    // Codi 2
}

4. if / else if / else

if (condicio1) {
    // Codi 1
} else if (condicio2) {
    // Codi 2
} else {
    // Si cap condició es compleix
}

5. Varios if independientes

if (condicio1) {
    // Codi 1
}

if (condicio2) {
    // Codi 2
}

if (condicio3) {
    // Codi 3
}

Cada condición se comprueba por separado.

Reglas importantes
  • La condición del if debe estar entre paréntesis ().
  • Las llaves {} delimitan el bloque de código que se ejecuta cuando se cumple la condición.
  • El else no lleva condición ni paréntesis.
  • El else if sí lleva una condición entre paréntesis.
  • No es obligatorio utilizar else.
  • Podemos utilizar tantos else if como necesitemos.
  • Podemos poner varios if independientes seguidos.
  • Si queremos que se puedan ejecutar varias acciones, cada una según su propia condición, utilizamos varios if independientes.
  • Si queremos elegir una sola alternativa entre varias, utilizamos if / else if / else.
Resumen para memorizar
  • if: si se cumple la condición, ejecuta el código.
  • else: si no se cumple la condición del if, ejecuta otra acción.
  • else if: si la condición anterior no se cumple, comprueba otra condición.
  • if / else if / else: permite elegir entre varias alternativas.
  • Varios if: permiten comprobar condiciones independientes y ejecutar varias acciones si se cumplen sus condiciones.

3.2 Operador ternari

L'operador ternari ? : és una forma compacta d'escollir entre dos valors segons una condició. Es diu ternari perquè treballa amb tres operands: una condició i dos valors possibles.

Sintaxi

condició ? valorSiCert : valorSiFals

El resultat de l'expressió és un valor, no una instrucció. Per això normalment s'utilitza per assignar-lo a una variable, per passar-lo com a argument o per retornar-lo: 

int edat = 20;
String tipus = (edat >= 18) ? "Adult" : "Menor";
System.out.println(tipus);  // Adult

Com funciona

  1. Es calcula la condició, que ha de donar true o false.
  2. Si és true, l'expressió pren el valor de valorSiCert.
  3. Si és false, l'expressió pren el valor de valorSiFals.

Només s'avalua un dels dos valors; l'altre no s'executa. A més, els dos valors han de ser compatibles amb el tipus on es guarda el resultat (per exemple, tots dos int o tots dos String).

D'if / else a ternari en una línia

Qualsevol if / else simple que només assigna un valor es pot convertir en un ternari. Aquest és el cas habitual: 

if (edat >= 18) {
    tipus = "Adult";
} else {
    tipus = "Menor";
}

Com que els dos blocs fan la mateixa acció (assignar a tipus), es poden reduir a una sola línia: 

tipus = (edat >= 18) ? "Adult" : "Menor";
if / else Ternari
if (condició) condició ?
valor assignat si és cert valorSiCert
else :
valor assignat si és fals valorSiFals
Regla pràctica

Converteix a ternari només quan el if / else assigna un valor i les dues opcions són curtes. Si hi ha diverses instruccions, bucles o lògica complexa, deixa el if / else: és més llegible.

Més exemples

Valor més gran entre dos enters:

int a = 10;
int b = 3;
int max = (a > b) ? a : b;  // 10

Valor absolut d'un nombre:

int num = -15;
int absValue = (num < 0) ? -num : num;  // 15

Directament dins d'un println:

int option = 10;
System.out.println(option > 0 ? "Positiu" : "No positiu");

Precedència

L'operador ternari té menys precedència que els operadors aritmètics i de comparació, però més que l'assignació. Per això int max = a > b ? a : b; funciona sense parèntesis. Els parèntesis són opcionals, però ajuden a llegir el codi. Consulta 2.3.6 Ordre de precedència.

Compost: un ternari pot contenir un altre ternari. S'usa per escollir entre més de dos valors, però no convé abusar-ne: 

int nota = 7;
String resultat = (nota >= 9) ? "Excel·lent"
                 : (nota >= 5) ? "Aprovat"
                 : "Suspès";

3.3 switch

Útil cuando comparas una variable contra muchos valores fijos.

switch (dia) {
    case 1: System.out.println("Lunes");     break;
    case 2: System.out.println("Martes");    break;
    case 3: System.out.println("Miércoles"); break;
    default: System.out.println("Otro día");
}

Desde Java 14 hay una sintaxis más moderna con flecha:

String nombre = switch (dia) {
    case 1 -> "Lunes";
    case 2 -> "Martes";
    case 3 -> "Miércoles";
    default -> "Otro día";
};

3.4 while / do-while

while: repite mientras se cumpla la condición.

int i = 0;
while (i < 5) {
    System.out.println(i);
    i++;
}

do-while: ejecuta al menos una vez, y luego mira la condición.

int n;
do {
    System.out.print("Número entre 1 y 10: ");
    n = sc.nextInt();
} while (n < 1 || n > 10);

3.5 for / for-each

El for clásico tiene tres partes: inicialización, condición, incremento.

// Contar de 0 a 9
for (int i = 0; i < 10; i++) {
    System.out.print(i + " ");
}

// De 10 a 1 (descendente)
for (int j = 10; j > 0; j--) {
    System.out.print(j + " ");
}

// De 2 en 2
for (int z = 0; z < 20; z += 2) {
    System.out.println(z);
}

El for-each es más limpio cuando solo quieres recorrer una colección o array:

int[] numeros = {1, 2, 3, 4, 5};
for (int n : numeros) {
    System.out.println(n);
}
break y continue
  • break → sale del bucle inmediatamente.
  • continue → salta a la siguiente iteración sin acabar la actual.

4. Métodos

Un método es un conjunto de instrucciones que realizan una tarea concreta. Sirve para reutilizar código y evitar repeticiones.

Anatomía de un método

Partes de un método
public static int suma(int a, int b) {
//  │      │      │   │    │
//  │      │      │   │    └─ parámetros (con tipo)
//  │      │      │   └────── nombre del método
//  │      │      └────────── tipo de retorno (int, void, String…)
//  │      └───────────────── static (opcional, lo veremos en POO)
//  └──────────────────────── modificador de acceso (public, private…)

    return a + b;          // ← devuelve un valor (obligatorio si retorno != void)
}

Métodos void

Cuando no devuelven nada, se declaran como void y no llevan return (o llevan un return; sin valor).

public static void saludar(String nombre) {
    System.out.println("Hola, " + nombre);
}

// Uso:
saludar("Anna");   // imprime "Hola, Anna"

Estáticos vs de instancia

  • Estáticos (static): se invocan sobre la clase. Ejemplo: Math.sqrt(16).
  • De instancia: se invocan sobre un objeto. Ejemplo: texto.length().

Ejemplo completo

public class Calculadora {

    public static int suma(int a, int b) {
        return a + b;
    }

    public static double media(int[] numeros) {
        int total = 0;
        for (int n : numeros) total += n;
        return (double) total / numeros.length;
    }

    public static void main(String[] args) {
        System.out.println(suma(5, 3));               // 8
        System.out.println(media(new int[]{2, 4, 6})); // 4.0
    }
}
Sobrecarga (overloading)

Puedes tener varios métodos con el mismo nombre si tienen parámetros distintos. Java elige cuál llamar según los argumentos.

public static int suma(int a, int b)       { return a + b; }
public static double suma(double a, double b) { return a + b; }
public static int suma(int a, int b, int c)   { return a + b + c; }

5. Arrays

Un array es una colección de tamaño fijo que guarda elementos del mismo tipo en posiciones consecutivas. Se accede por índice, que empieza en 0.

public String frontBack(String str) {

    String resultat = "";

    if (str.length() == 1) {
        return str;
    }

    char primer = str.charAt(0);
    char ultim = str.charAt(str.length() - 1);

    for (int i = 0; i < str.length(); i++) {

        if (i == 0) {
            resultat = resultat + ultim;
        }
        else if (i == str.length() - 1) {
            resultat = resultat + primer;
        }
        else {
            resultat = resultat + str.charAt(i);
        }
    }

    return resultat;
}

7. Programación Orientada a Objetos (POO)

La POO es un paradigma de programación basado en objetos: estructuras que combinan datos (atributos) y comportamiento (métodos). Java es un lenguaje orientado a objetos por naturaleza.

7.1 Clases y objetos

Una clase es un plano o plantilla. Un objeto es una instancia concreta de esa clase.

Por ejemplo: la clase Estudiante describe cómo son todos los estudiantes (tienen nombre, edad, id…). Un objeto sería un estudiante concreto: Anna, 17 años, id 42.

Una clase tiene tres partes:

  • Atributos: las características del objeto.
  • Constructor: cómo se crea un objeto.
  • Métodos: las acciones que puede hacer.
Estudiante.java
public class Estudiante {

    // 1. Atributos (privados)
    private String nombre;
    private byte edad;
    private String id;

    // 2. Constructor
    public Estudiante(String nombre, byte edad, String id) {
        this.nombre = nombre;
        this.edad   = edad;
        this.id     = id;
    }

    // 3. Métodos
    public void saludar() {
        System.out.println("Hola, soy " + nombre);
    }
}

Y así se crea e usa un objeto:

Estudiante anna = new Estudiante("Anna", (byte) 17, "EST001");
anna.saludar();      // imprime "Hola, soy Anna"
La palabra clave this

this hace referencia al objeto actual. Sirve para distinguir el atributo (this.nombre) del parámetro (nombre) cuando se llaman igual.

7.2 Encapsulación (getters y setters)

Los atributos suelen ser private: solo se pueden tocar desde dentro de la clase. Esto evita modificaciones accidentales desde fuera. Para acceder a ellos desde fuera, usamos getters y setters:

public class Estudiante {
    private String nombre;

    // Getter: para leer el atributo
    public String getNombre() {
        return nombre;
    }

    // Setter: para modificarlo (con posibilidad de validar)
    public void setNombre(String nombre) {
        if (nombre != null && !nombre.isEmpty()) {
            this.nombre = nombre;
        }
    }
}

(sin nada)Dentro del mismo paquete

7.3 Herencia

La herencia permite que una clase nueva reutilice los atributos y métodos de una clase ya existente. Se usa la palabra extends.

Vehículo y Coche
public class Vehiculo {
    protected String matricula;
    protected String marca;

    public Vehiculo(String matricula, String marca) {
        this.matricula = matricula;
        this.marca = marca;
    }

    public void arrancar() {
        System.out.println("El vehículo arranca");
    }
}

public class Coche extends Vehiculo {
    private byte numPlazas;

    public Coche(String matricula, String marca, byte numPlazas) {
        super(matricula, marca);   // llama al constructor del padre
        this.numPlazas = numPlazas;
    }
}
La palabra clave super
  • super(...) llama al constructor del padre. Si lo usas, debe ser la primera línea del constructor.
  • super.metodo() llama a un método del padre desde la subclase.
  • Todas las clases heredan implícitamente de Object.

Tipos de herencia

  • Simple: una subclase hereda de una superclase.
  • Jerárquica: varias subclases comparten una superclase.
  • Multinivel: cadena A → B → C.
Java no permite herencia múltiple

Una clase solo puede tener un padre. Para simular herencia múltiple se usan interfaces (lo veremos en 7.6).

7.4 Polimorfismo

Polimorfismo significa "muchas formas": un mismo objeto puede comportarse de varias maneras según el contexto.

Polimorfismo de asignación

Puedes asignar un objeto de una subclase a una variable de la superclase:

Vehiculo v;
v = new Coche("1234ABC", "Seat", (byte) 5);
v = new Moto("5678DEF", "Honda");

v.arrancar();   // funciona aunque v sea de tipo Vehiculo

Si necesitas acceder a métodos específicos de la subclase, haz casting:

Vehiculo v = new Coche(...);
Coche c = (Coche) v;     // casting explícito
c.abrirMaletero();
ClassCastException

Si haces un casting inválido (intentas convertir un Vehiculo que en realidad es una Moto a Coche), Java lanza ClassCastException. Comprueba antes con instanceof:

if (v instanceof Coche c) {
    c.abrirMaletero();
}

Sobreescritura (overriding)

Una subclase puede redefinir un método del padre. Se marca con @Override:

public class Coche extends Vehiculo {
    @Override
    public void arrancar() {
        System.out.println("El coche arranca con la llave");
    }
}

Sobrecarga (overloading)

Varios métodos con el mismo nombre pero distintos parámetros (ya visto en el apartado de Métodos):

public Cuadrado(double lado) { ... }
public Cuadrado(double x, double y, double lado) { ... }

7.5 Clases abstractas

Una clase abstracta es una clase que no se puede instanciar directamente. Sirve para definir un esqueleto común que las subclases deben completar.

Se marca con abstract. Puede tener métodos abstractos (sin cuerpo) y métodos normales.

public abstract class Figura {
    protected double x, y;

    // Método abstracto: las subclases DEBEN implementarlo
    public abstract double area();

    // Método normal: las subclases lo heredan tal cual
    public void mover(double dx, double dy) {
        this.x += dx;
        this.y += dy;
    }
}

public class Circulo extends Figura {
    private double radio;

    @Override
    public double area() {
        return Math.PI * radio * radio;
    }
}
Características
  • No se pueden instanciar directamente (new Figura() daría error).
  • Pueden tener constructores (los llaman las subclases con super).
  • Pueden mezclar métodos abstractos y normales.
  • Las subclases concretas deben implementar todos los métodos abstractos.

7.6 Interfaces

Una interfaz define un contrato: una lista de métodos que las clases que la implementen deben tener. Es como una clase abstracta sin atributos ni constructor.

public interface Movible {
    void mover();
    void saltar();
}

public class Coche implements Movible {
    @Override
    public void mover()  { System.out.println("Rodando"); }

    @Override
    public void saltar() { System.out.println("Los coches no saltan…"); }
}

Herencia múltiple con interfaces

Una clase puede implementar varias interfaces a la vez (separadas por coma). Por eso decimos que en Java se simula la herencia múltiple con interfaces:

public class Coche implements Movible, Reparable, Repostable {
    // Implementar todos los métodos de las tres interfaces
}

Interface vs Clase abstracta

Cuándo usar cada uno
  • Interface: cuando quieres definir qué debe hacer algo (un contrato), sin importar el cómo.
  • Clase abstracta: cuando varias clases comparten código y solo necesitas que cada una complete unos pocos métodos.

8. Colecciones

Las colecciones son estructuras dinámicas para guardar grupos de elementos. A diferencia de los arrays, crecen y se reducen según necesites: no tienes que fijar el tamaño al crearlas.

Las tres familias principales son List, Set y Map.

8.1 List

Una List es una colección ordenada que permite elementos repetidos y acceso por índice.

  • ArrayList: la más usada. Acceso rápido por índice e iteración eficiente.
  • LinkedList: rápida para insertar/eliminar al principio o al final.
import java.util.ArrayList;
import java.util.List;

List<String> nombres = new ArrayList<>();
nombres.add("Anna");
nombres.add("Marc");
nombres.add("Júlia");
nombres.add("Anna");    // ← se permite repetido

System.out.println(nombres.get(0));      // Anna
System.out.println(nombres.size());      // 4
System.out.println(nombres.contains("Marc")); // true
nombres.remove(0);                       // borra el primero

// Recorrer con for-each
for (String n : nombres) {
    System.out.println(n);
}

8.2 Set

Un Set es una colección que NO admite elementos repetidos. Si añades un elemento que ya está, simplemente no se inserta.

8.3 Map

Un Map es una colección de pares clave → valor (también llamado diccionario). Las claves no se repiten; los valores sí.

ImplementaciónOrdenVelocidad
HashMapSin ordenMás rápido (recomendado por defecto)
LinkedHashMapPor inserciónIntermedio
TreeMapPor claveMás lento (pero ordenado)
 
import java.util.HashMap;
import java.util.Map;

Map<String, Integer> edades = new HashMap<>();
edades.put("Anna", 17);
edades.put("Marc", 22);
edades.put("Júlia", 19);

System.out.println(edades.get("Anna"));         // 17
System.out.println(edades.containsKey("Marc")); // true
System.out.println(edades.get("Pere"));         // null (no existe)

// Iteración por entradas
for (Map.Entry<String, Integer> e : edades.entrySet()) {
    System.out.println(e.getKey() + " → " + e.getValue());
}

Las colecciones usan genéricos: indicas entre <> el tipo de los elementos. Así Java te avisa en tiempo de compilación si intentas meter algo de otro tipo.

List<String> lista = new ArrayList<>();
lista.add("hola");
lista.add(42);   // ❌ ERROR de compilación

9. Excepciones

Una excepción es un error en tiempo de ejecución que interrumpe el flujo normal del programa (por ejemplo, dividir entre 0 o acceder a una posición inexistente de un array). Java nos permite capturar estas excepciones y reaccionar ante ellas.

try / catch / finally

try {
    // Código que puede lanzar una excepción
    int resultado = 10 / 0;
} catch (ArithmeticException e) {
    // Qué hacer si ocurre la excepción
    System.out.println("Error: " + e.getMessage());
} finally {
    // Se ejecuta SIEMPRE (con o sin excepción)
    System.out.println("Fin del bloque");
}

Dos familias de excepciones

TipoHay que capturar obligatoriamenteEjemplos
Runtime (Unchecked) No (el compilador no obliga) NullPointerException, ArithmeticException, ArrayIndexOutOfBoundsException, NumberFormatException
Checked Sí (con try/catch o throws) IOException, SQLException, FileNotFoundException

throw y throws

throw lanza una excepción manualmente:

public void setEdad(int edad) {
    if (edad < 0) {
        throw new IllegalArgumentException("La edad no puede ser negativa");
    }
    this.edad = edad;
}

throws avisa de que un método puede lanzar una excepción (no la captura, la delega):

public void leerFichero(String ruta) throws IOException {
    BufferedReader br = new BufferedReader(new FileReader(ruta));
    // ...
}

Capturar varias excepciones a la vez

try {
    int n = Integer.parseInt(args[0]);
    int[] a = new int[n];
    a[100] = 1;
} catch (NumberFormatException | ArrayIndexOutOfBoundsException e) {
    System.out.println("Argumento inválido: " + e.getMessage());
}

Excepciones personalizadas

Puedes crear tus propias excepciones extendiendo Exception o RuntimeException:

public class SaldoInsuficienteException extends RuntimeException {
    public SaldoInsuficienteException(String mensaje) {
        super(mensaje);
    }
}

// Uso
public void retirar(double importe) {
    if (importe > saldo) {
        throw new SaldoInsuficienteException(
            "No hay saldo suficiente para retirar " + importe);
    }
    saldo -= importe;
}
try-with-resources (Java 7+)

Cuando trabajas con recursos que hay que cerrar (ficheros, conexiones), usa try-with-resources: Java los cierra automáticamente.

try (BufferedReader br = new BufferedReader(new FileReader("a.txt"))) {
    System.out.println(br.readLine());
}   // ← br.close() se llama solo aquí

Las 5 reglas de oro de Java
  1. Una clase por fichero, y el nombre del fichero = nombre de la clase pública.
  2. Atributos siempre private, y acceso con getters/setters.
  3. Compara Strings con .equals(), nunca con ==.
  4. Usa genéricos en colecciones: List<String>, no List a secas.
  5. Marca con @Override los métodos que sobreescribes — te ahorra muchos bugs.
