1. Particions i sistemes de fitxers

Un sistema de fitxers (filesystem) és l'estructura que defineix com s'organitzen i s'accedeixen les dades als dispositius d'emmagatzematge: estableix com es guarden els fitxers, carpetes, enllaços, permisos, etc. Sense un sistema de fitxers els discos serien només un espai en brut sense cap manera d'identificar els continguts.

Discs i particions

Un disc és un dispositiu físic d'emmagatzematge. Una partició és una subdivisió lògica d'un disc físic, definida en una taula de particions. El disc és el suport físic, la partició és una divisió del disc, i el filesystem és la manera com es gestionen els fitxers dins d'aquesta partició.

A GNU/Linux, tot és un arxiu. Cada partició s'identifica com un dispositiu dins de /dev:

  • /dev/sda1, /dev/sda2 — discs SATA, SCSI, USB
  • /dev/nvme0n1p1 — discs NVMe
  • /dev/mmcblk0p1 — targetes SD / memòria extraïble
  • /dev/hdX — discs IDE antics

1.1 MBR vs GPT

CaracterísticaMBRGPT
Any1983 (MS-DOS)Modern
Particions primàriesMàxim 4Fins a 128
Màxim disc2 TBSense límit pràctic
Còpia seguretatNoSí (taula duplicada)
GUID únicNoSí (128 bits)
Boot sector

MBR emmagatzema la taula de particions al primer sector del disc (Boot Sector). GPT utilitza còpies de seguretat de la taula de particions per a més seguretat.

1.2 Gestionar particions MBR amb fdisk

fdisk és l'eina clàssica per gestionar taules de particions MBR.

fdisk
# fdisk /dev/sda
  m — mostra l'ajuda
  p — mostra la taula de particions actual
  n — crea una nova partició
  d — elimina una partició
  t — canvia el tipus
  w — desa els canvis
  q — surt sense desar
Atenció

Els canvis no s'apliquen fins que escrius w.

Tipus de particions MBR:

  • Primary — màxim 4.
  • Extended — conté diverses particions lògiques (logical).

1.3 Gestionar particions GPT amb gdisk

gdisk és com fdisk però per a discs GPT.

gdisk
# gdisk /dev/sdb
  p — mostra les particions
  n — crea nova partició
  d — elimina
  s — ordena
  r — menú de recuperació
  w — desa els canvis
Atenció

Els canvis no s'apliquen fins que escrius w.

1.4 Crear sistemes de fitxers amb mkfs

Després de particionar, cal formatejar cada partició amb un sistema de fitxers.

ext2 / ext3 / ext4

# mkfs.ext4 /dev/sdb1
# mke2fs -t ext4 /dev/sdb1

# Opcions útils:
  -b       — mida de bloc
  -c       — comprova blocs dolents
  -L       — etiqueta del volum
  -n       — simulació sense escriure

XFS

# mkfs.xfs /dev/sda1

# Opcions:
  -b size=4096   — mida del bloc
  -L label       — etiqueta
  -N             — mode simulació

VFAT / FAT32

# mkfs.vfat /dev/sdc1

# Opcions:
  -F 32     — selecciona FAT32
  -n NAME   — etiqueta

exFAT

# mkfs.exfat /dev/sdb1

# Opcions:
  -i VOL_ID   — ID del volum
  -n NAME     — nom del volum

1.5 Swap

El swap no és un sistema de fitxers tradicional, sinó una àrea del disc que el sistema utilitza com a memòria virtual quan la RAM s'esgota. Això permet continuar treballant encara que la memòria física estigui plena, tot i que amb un rendiment més lent.

# Crear una partició swap
# mkswap /dev/sda2
# swapon /dev/sda2

1.6 Btrfs

Btrfs és un sistema de fitxers modern amb característiques avançades:

  • Suport multi-dispositiu (RAID, mirroring, etc.)
  • Subvolums i snapshots
  • Compressió automàtica (zlib, lzo, zstd)
# Crear un sistema de fitxers Btrfs
# mkfs.btrfs /dev/sdb1
# mkfs.btrfs /dev/sdb1 -L "NewDisk"

# Crear un subvolum
# btrfs subvolume create /mnt/disk/BKP

# Crear un snapshot
# btrfs subvolume snapshot /mnt/disk /mnt/disk/snap

1.7 L'eina parted

parted pot fer-ho tot (particions + formateig), però amb més risc si no vas amb compte. A diferència de fdisk i gdisk, parted aplica els canvis immediatament.

parted
# parted /dev/sdb
  print              — mostra informació del disc
  mklabel gpt|msdos  — crea una taula nova
  mkpart primary ext4 1MiB 100MiB  — crea una partició
  rm 2               — elimina la partició 2
  resizepart 3 350MiB — redimensiona
  rescue START END   — intenta recuperar
parted

parted aplica els canvis immediatament, sense necessitat d'escriure w. Aneu amb compte!

Notes finals
  • Les ordres mkfs creen sistemes de fitxers, no particions.
  • fdisk i gdisk modifiquen la taula de particions.
  • parted pot fer-ho tot, però amb més risc.
  • Sempre fes còpia de seguretat abans de modificar particions.

2. RAID

2.1 Què és RAID

RAID (Redundant Array of Independent Disks) és una tècnica que permet combinar diversos discos físics (o virtuals) per aconseguir:

  • Més velocitat (striping) ⏱️
  • Més seguretat / redundància (mirroring, paritat) 🛟
  • O una combinació de totes dues

Els tres pilars del RAID

  1. Striping — divideix les dades entre discos → + velocitat, però cap seguretat.
  2. Mirroring — còpia exacta del disc → + seguretat, però gasta més espai.
  3. Paritat — guarda informació de correcció per reconstruir dades si un disc falla.

2.2 Quadre comparatiu RAID

RAIDQuè faLecturaEscripturaRedundància
0Striping⭐⭐⭐⭐⭐⭐❌ cap
1Mirroring⭐⭐⭐⭐⭐⭐ (1 disc)
5Striping + Paritat⭐⭐⭐⭐⭐⭐ (1 disc)
6Striping + doble paritat⭐⭐⭐⭐⭐⭐⭐ (2 discos)
10Mirroring + Striping⭐⭐⭐⭐⭐⭐⭐⭐ (1 per parella)

2.3 mdadm — gestionar RAIDs a Linux

mdadm és l'eina que gestiona RAIDs a Linux.

Instal·lació
$ sudo apt install mdadm

Comandes principals:

  • mdadm --create — crear arrays RAID
  • mdadm --stop — parar arrays
  • mdadm --detail — mirar què tens muntat
  • mdadm --zero-superblock — esborrar metadades

Crear RAID 0

$ sudo ./fada_dels_discos.sh disc_0
$ sudo ./fada_dels_discos.sh disc_1
$ sudo mdadm --create /dev/md0 --level=0 \
    --raid-devices=2 /dev/loop5 /dev/loop6

Crear RAID 1

$ sudo mdadm --create /dev/md1 --level=1 \
    --raid-devices=2 /dev/loop7 /dev/loop8

Crear RAID 5

$ sudo mdadm --create /dev/md5 --level=5 \
    --raid-devices=3 /dev/loop9 /dev/loop10 /dev/loop11

Crear RAID 6

$ sudo mdadm --create /dev/md6 --level=6 \
    --raid-devices=4 /dev/loop12 /dev/loop13 /dev/loop14 /dev/loop15

Crear RAID 10

$ sudo mdadm --create /dev/md10 --level=10 \
    --raid-devices=4 /dev/loop16 /dev/loop17 /dev/loop18 /dev/loop19

Aturar un RAID

$ sudo umount /dev/md0
$ sudo mdadm --stop /dev/md0
mdadm: stopped /dev/md0

2.4 Loop devices

Els loop devices (com /dev/loop5) són arxius que es comporten com si fossin discos de veritat. Són perfectes per practicar RAID sense destruir res real.

  • Funcionen igual que un disc: s'hi poden fer particions i formats.
  • Desapareixen quan els desmuntes o esborres l'arxiu.
  • Són perfectes per fer pràctiques segures.
Arrays

L'array és el «disc virtual gran» que resulta de combinar diversos discos petits. Apareix com /dev/md0, /dev/md1, etc. Sobre aquest /dev/mdX és on faràs la taula de particions, crearàs sistemes de fitxers i muntaràs directoris.

3. La Fada dels Discos

La fada_dels_discos.sh és una eina Unix-style minimalista que:

  • Crea discos virtuals com a fitxers dispersos (*.disk)
  • Els converteix en loop devices (/dev/loopX)
  • De manera simple, clara i Unix-friendly

Invocar la fada

$ wget -q https://raw.githubusercontent.com/sjornetc/aux/main/fada_dels_discos.sh
$ chmod +x fada_dels_discos.sh

Ús bàsic

$ sudo ./fada_dels_discos.sh -s 1G unicorn
🧚‍♀ Creat l'arxiu «unicorn.disk» (mida 100M)
🧚‍♀ Loop creat! disc_0.disk -> /dev/loop7

Opcions

OpcióDescripció
-s, --size MIDAMida del disc (1G, 200M, 128k)
-q, --quietSilencia logs; stdout només conté /dev/loopX
--helpMostra ajuda
--versionMostra versió (2.2.0), autora i llicència

Què hi pots fer amb els discos màgics?

  • Crear particions (fdisk)
  • Crear sistemes de fitxers (mkfs.ext4)
  • Muntar-los (mount)
  • Fer-los servir en RAIDs (mdadm)
  • Experimentar sense por d'espatllar res

Netejar

$ sudo umount /mnt/unicorn
$ sudo losetup -d /dev/loop7
$ rm unicorn.disk

4. FileNest

FileNest és una eina que crea o elimina una estructura de carpetes i fitxers simulant una casa.

Ús
filenest [OPCIONS] [PATH]

Opcions:
  -b, --build       Crea l'estructura
  -d, --delete      Elimina l'estructura
  -r, --replace     Si la carpeta existeix, l'elimina i la recrea
  -h, --help        Mostra l'ajuda

Exemples:
  filenest -b                  → construeix la casa a ./house
  filenest -br ~/projects/home → reconstruir la casa allà
  filenest -d                  → elimina ./house

Per executar directament des del repositori de GitHub:

bash <(wget -qO- https://raw.githubusercontent.com/sjornetc/filenest/main/run.sh) [OPCIONS] [PATH]

7. Logs del sistema

Gestió de registres del sistema (RA1 108.2).

rsyslog

Sistema de logging tradicional. Les configuracions es troben a /etc/rsyslog.conf i /etc/rsyslog.d/.

# Fitxers de log habituals
/var/log/syslog      — missatges del sistema
/var/log/auth.log    — autenticacions
/var/log/kern.log    — missatges del kernel

systemd-journald

Sistema de logging modern de systemd.

# Veure logs
journalctl
journalctl -u servei    — logs d'un servei concret
journalctl -f            — mode follow (temps real)
journalctl --since "1 hour ago"

8. SSH / OpenSSH

Configuració i ús d'SSH per accés remot segur (RA1 110.3).

Connexió bàsica

ssh usuari@servidor
ssh -p 2222 usuari@servidor    — port personalitzat

Claus SSH (autenticació sense contrasenya)

# Generar clau
ssh-keygen -t rsa -b 4096

# Copiar clau pública al servidor
ssh-copy-id usuari@servidor

# Fitxers importants:
~/.ssh/id_rsa          — clau privada
~/.ssh/id_rsa.pub      — clau pública
~/.ssh/authorized_keys — claus autoritzades al servidor

Configuració del servidor (/etc/ssh/sshd_config)

Port 22
PermitRootLogin no
PasswordAuthentication yes/no
PubkeyAuthentication yes

9. Scripting a Linux

Creació de scripts de shell (RA1 105.2).

Estructura bàsica

#!/bin/bash
# El meu primer script

echo "Hola, món!"

# Variables
NOM="Anna"
echo "Hola, $NOM"

# Llegir entrada
read -p "Com et dius? " USUARI
echo "Hola, $USUARI"

Condicionals

if [ "$NOM" = "Anna" ]; then
    echo "Ets l'Anna"
elif [ "$NOM" = "Pere" ]; then
    echo "Ets en Pere"
else
    echo "No et conec"
fi

Bucles

# for
for i in {1..5}; do
    echo "Iteració $i"
done

# while
COUNT=0
while [ $COUNT -lt 5 ]; do
    echo $COUNT
    ((COUNT++))
done

Funcions

saludar() {
    echo "Hola, $1!"
}

saludar "Anna"
Consell

Recorda donar permisos d'execució al script: chmod +x script.sh
